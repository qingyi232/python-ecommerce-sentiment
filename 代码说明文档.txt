========================================
一、项目概述
========================================

本系统是一个基于 Python 的电商平台商品评论情感分析与用户需求挖掘平台。

核心功能：
1. 数据采集：支持京东等电商平台评论数据爬取
2. 情感分析：基于 SnowNLP / BERT 对评论进行正面/负面/中性分类
3. 需求挖掘：基于 LDA 主题模型提取用户核心需求和关键词
4. 可视化展示：多维度 ECharts 图表展示分析结果
5. 数据管理：商品、评论、用户、爬取任务的增删改查

系统角色：
- 管理员（admin）：拥有所有功能权限，包括用户管理
- 商家（merchant）：查看分析数据、管理商品
- 普通用户（user）：查看分析结果

========================================
四、后端代码说明
========================================

【4.1 应用入口】
- run.py：创建 Flask 应用并启动开发服务器（端口 5000）
- app/__init__.py：应用工厂函数 create_app()
  - 初始化 SQLAlchemy、JWT、CORS
  - 注册所有蓝图（Blueprint）路由
  - 自动创建数据库表（db.create_all）

【4.2 数据模型 models/】
- user.py (User)：
  字段：id, username, password_hash, email, nickname, avatar, role, status, created_at
  方法：set_password()（bcrypt 哈希）, check_password()（密码验证）

- product.py (Product)：
  字段：id, name, category, brand, price, image_url, source_platform, review_count, avg_sentiment
  关联：一对多关联 Review

- review.py (Review)：
  字段：id, product_id, content, cleaned_content, rating, reviewer_name, sentiment_score, sentiment_label, is_analyzed, keywords
  关联：外键关联 Product

- sentiment.py (SentimentResult)：
  字段：id, product_id, total_reviews, positive/negative/neutral_count, avg_score, positive/negative/neutral_ratio, top_positive/negative_words, algorithm, analyzed_at

- demand.py (DemandTopic + DemandKeyword)：
  DemandTopic：id, product_id, topic_name, topic_words, weight
  DemandKeyword：id, product_id, keyword, frequency

- crawl_task.py (CrawlTask)：
  字段：id, task_name, platform, keyword, target_url, status, success_count, fail_count, created_by

【4.3 路由 routes/】
- auth.py：登录(POST /login)、注册(POST /register)、获取/更新个人信息
- review.py：评论 CRUD + 商品 CRUD + 分类查询
- analysis.py：运行情感分析、获取分析结果、运行需求挖掘、获取挖掘结果
- crawl.py：爬取任务创建、启动、删除
- dashboard.py：统计数据、最新评论、分类统计、情感趋势
- user.py：用户列表、状态更新、删除（仅管理员权限）
- upload.py：图片上传与访问
- visualization.py：服务端 matplotlib 图表生成（备用）

【4.4 服务层 services/】
- sentiment_service.py：
  analyze() 方法遍历所有评论 → 文本清洗 → SnowNLP/BERT 计算情感分值 → 分类为正面/负面/中性 → 存入 SentimentResult 表
  
- demand_service.py：
  analyze() 方法收集评论 → jieba 分词 → 构建词袋 → gensim LDA 主题模型 → 提取主题和关键词 → 存入 DemandTopic/DemandKeyword 表

- crawl_service.py：
  支持真实爬取（Scrapy/requests）和示例数据
  爬取的评论自动存入 Product + Review 表

- text_processor.py：
  clean_text()：去除 HTML/URL/特殊字符
  segment()：jieba 分词 + 去停用词
  extract_keywords()：TF-IDF 关键词提取

========================================
八、核心算法说明
========================================

【8.1 情感分析 - SnowNLP】
SnowNLP 是一个基于朴素贝叶斯的中文情感分析库。
流程：
  评论原文 → 文本清洗 → SnowNLP.sentiments → 情感分值(0~1)
  分值 >= 0.6 → 正面
  分值 <= 0.4 → 负面
  其他 → 中性

【8.2 情感分析 - BERT（可选）】
使用 HuggingFace transformers 加载预训练的中文情感分析模型。
模型：uer/roberta-base-finetuned-jd-binary-chinese
流程：
  评论原文 → 截断到512字符 → BERT 推理 → positive/negative 标签+置信度 → 映射为 0~1 分值
  如果 BERT 模型加载失败，自动回退到 SnowNLP

【8.3 需求挖掘 - LDA 主题模型】
LDA（Latent Dirichlet Allocation）潜在狄利克雷分配。
流程：
  评论集合 → jieba 分词 → 去停用词 → 构建词袋(Bag of Words) → gensim LDA 训练
  → 输出 N 个主题（每个主题含多个关键词和权重）
  → 统计所有评论中关键词频率

【8.4 文本预处理】
- 去除 HTML 标签、URL、邮箱
- 去除特殊字符和多余空格
- jieba 精确模式分词
- 去除停用词（长度<2 或在停用词表中）
- TF-IDF 关键词提取


========================================
九、数据流说明
========================================

【评论分析全流程】
  1. 数据来源：init_db.py 预置 / 爬虫采集 / 手动录入
  2. 存储：评论存入 reviews 表
  3. 情感分析：用户点击"开始分析"
     → 后端读取该商品的所有评论
     → 逐条进行文本清洗 + SnowNLP/BERT 打分
     → 更新 reviews 表的 sentiment_score 和 sentiment_label
     → 汇总统计写入 sentiment_results 表
     → 更新 products 表的 avg_sentiment
  4. 需求挖掘：用户点击"开始挖掘"
     → 后端读取该商品的所有评论
     → 分词 → LDA 主题建模
     → 写入 demand_topics 和 demand_keywords 表
  5. 可视化：前端读取分析结果 → ECharts 渲染图表

【数据实时性保证】
  - 所有写操作（增删改）通过 SQLAlchemy 的 db.session.commit() 实时提交
  - 删除商品时级联删除其所有评论
  - 删除评论时自动更新商品的 review_count
  - 运行分析时覆盖同商品同算法的旧结果
  - 前端通过 API 实时查询最新数据，图表随数据变化
